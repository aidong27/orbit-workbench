# Orbit Workbench 0.2.0-alpha.3

`0.2.0-alpha.3` 是一次“连接成功率与可用性”升级：修复本机 Grok Build 明明可用、界面却因扩展通知误判而连接失败的问题，并重新设计首次引导、连接恢复、空任务起步与全局阅读体验。

## 重点变化

- **修复 Grok 0.2.112 连接失败**：安全 NDJSON 边界会验证并忽略结构合法的 `_x.ai/*` 扩展通知，不再把官方 CLI 的 MCP、公告和设置更新误判为非法协议帧；未知通知、畸形参数与超大帧仍会被拒绝。
- **连接状态不再失真**：检测到 CLI 只显示“CLI 已检测”；只有 ACP 初始化和认证完成后才显示“已连接”。
- **失败后可直接恢复**：欢迎页、输入区、顶部状态和连接中心均提供重新检测/连接入口，无需重启应用。
- **完整连接诊断**：连接中心展示 CLI 路径、CLI 版本、Agent 版本、故障代码与脱敏详情，并可一键复制。
- **真正的首次引导**：首次启动使用真实空状态，按“检测 CLI → 连接 ACP → 选择工作区 → 描述任务”引导，不再用虚构演示项目占据首屏。
- **空任务不再是空白画布**：新工作区提供四个中文安全模板，包括只读检查、先给计划、Git 审查和错误定位；点击只填入草稿，不会自动发送。
- **离线草稿更诚实**：Grok 未连接时仍可撰写并保留会话级草稿，但发送和模式切换会明确禁用。
- **系统性提高可读性**：基础字号提升到 15px，信息文字不低于 11px；正文、辅助文字、占位符和关键状态的对比度统一提高。
- **窄窗口不再挤压对话**：窗口宽度不超过 1180px 时，右侧检查器改为覆盖式抽屉。
- **键盘与语义改进**：连接状态成为可操作按钮；设置对话框加入焦点圈定和恢复；检查器支持标准 tab 语义与左右方向键；命令面板支持上下键、Home/End 和当前项语义。
- **合法空状态可持久化**：本地状态升级为 v3，支持没有工作区的正常首次启动；v2/v1 迁移成功写入 v3 后才清除旧键，失败时保留原数据。
- **错误不再依赖阻塞式弹窗**：工作区、Git 与权限错误改为非阻塞通知；Electron IPC 包装文案会从用户诊断中移除。

## 验证

- 类型检查、Biome、生产依赖许可证校验与 Electron/Vite 生产构建。
- 27 个测试文件、131 项自动化测试。
- 安全协议流测试覆盖合法 vendor notification、带 ID request、未知通知、畸形参数与 4 MiB 帧限制。
- 连接控制器测试覆盖 CLI 缺失、CLI 已检测、ACP 成功和 IPC 错误净化。
- 首次引导、离线 Composer、安全任务模板、v2/v1 → v3 迁移与空状态均有回归测试。

## 升级说明

- v2 和 v1 本地界面数据会自动迁移到 v3；迁移不会恢复旧 ACP Session ID。
- 已保存且含时间线的会话仍明确标记为“仅本地历史”，不会伪装成已恢复代理上下文。
- 升级不会清除真实工作区、会话历史或用户草稿；首次启动不再创建演示实体。
- ACP Session ID、权限请求、已确认模式和工具原始输入/输出不会跨进程持久化。

## 已知限制

- 仍不支持从 Grok Build 上游会话库恢复完整代理上下文。
- Windows 与 macOS 安装包尚未正式签名或 Apple 公证；macOS hardened runtime 尚未启用。
- Windows 的实际显示缩放仍需要在更多物理设备上人工验证。
- 当前仍是 Alpha。请优先在有版本控制、可回滚的工作区测试。
