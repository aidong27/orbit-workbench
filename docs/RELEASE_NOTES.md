# Orbit Workbench 0.2.0-alpha.2

`0.2.0-alpha.2` 是一次“状态真实性”升级：界面展示的历史连续性、会话模式、流式消息和权限来源，必须与当前 ACP 连接确认的事实一致。

## 重点变化

- **历史不再伪装成在线上下文**：重启后保存的旧时间线标记为“仅本地历史”，不能在原视觉会话中静默新建空白 ACP session。继续工作需要显式创建新任务。
- **模式以服务端确认为准**：客户端区分请求模式和已确认模式；切换失败会保留原模式并显示原因。
- **类型化 ACP 边界**：SDK 原始事件只存在于主进程，经过限长和净化后转换为 renderer 专用的判别联合事件。
- **正确归并流式内容**：消息和过程分片按 `messageId` 更新；计划支持 items、Markdown、file 和 remove 事件。
- **权限来源更明确**：弹窗显示来源工作区、绝对路径、会话和后台请求提示；工具与权限内容受字符串、深度、集合项数和总大小限制。
- **中文输入更安全**：IME 仍在组词时 Enter 不会发送；未发送草稿按会话隔离。
- **任务状态能够收敛**：长任务采用事件空闲 watchdog，等待权限时暂停；取消或通道失效后会在有限时间内结束状态，必要时重建本地代理连接。
- **创建期事件不再丢失**：`session/new` 返回前到达的模式、命令或计划事件会保序缓冲；超过安全上限或报告未声明模式时连接会明确失败。
- **最小化子进程环境**：Grok 子进程只接收白名单中的系统运行时、Grok/xAI、代理和证书变量，Node/Electron 注入变量始终被拒绝。
- **版本化本地状态**：v2 持久化信封包含 schema 版本，加载时校验、迁移 v1 数据并修复失效引用。
- **协议回归不再只靠 reducer**：测试会真实启动 Fake ACP 子进程，通过 stdio/NDJSON 覆盖交错消息、计划、权限和模式拒绝；组件测试覆盖 IME、权限来源和工具终态。
- **畸形协议帧不进入日志**：ACP stdout 在 SDK 前完成帧大小与 JSON-RPC/通知结构校验，错误只返回固定、脱敏的诊断信息。
- **打包基线进一步加固**：Electron fuses 禁用 Node 注入与运行时调试入口，启用 ASAR 完整性校验；平台 CI 验证最终安装/便携产物并生成 SHA-256 清单。
- **第三方许可随包交付**：生产依赖、Electron 与 Chromium 的完整许可正文会进入最终安装包，并由 CI 校验。

## 升级说明

- 首次启动本版本时，兼容的 v1 本地界面数据会自动迁移到 v2。
- 已保存的对话仍可查看，但不会被描述为已恢复的 Grok Build 代理上下文。
- 演示工作区不会写入正式持久化数据。
- ACP Session ID、权限请求、已确认模式和工具原始输入/输出不会跨进程持久化。

## 已知限制

- 仍不支持从 Grok Build 上游会话库恢复完整代理上下文。
- 已有聚焦核心路径的 Fake ACP Agent 集成测试，但尚未覆盖全部崩溃、停滞和平台进程树场景。
- Windows 与 macOS 安装包尚未正式签名或 Apple 公证；macOS hardened runtime 尚未启用。
- 当前仍是 Alpha。请优先在有版本控制、可回滚的工作区测试。
