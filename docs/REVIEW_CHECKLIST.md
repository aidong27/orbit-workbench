# 私有预览人工验收清单

## 启动与连接

- [ ] `pnpm dev` 能打开“星轨工作台”。
- [ ] 左下角显示“Grok 已连接”。
- [ ] 设置页说明的是本机 ACP，且没有出现 API 密钥输入框。
- [ ] 选择文件夹时只出现系统目录选择器。

## 中文界面

- [ ] 1500×960 下左侧会话、中间时间线、右侧检查器同时可见。
- [ ] 1024×768 下没有横向滚动或中文遮挡。
- [ ] 长文件名、命令和回复可滚动或省略，不撑破布局。
- [ ] 演示会话明确标记“界面预览”。

## 真实任务

- [ ] 打开一个可回滚的测试仓库。
- [ ] 新建任务并发送一个只读解释请求。
- [ ] 回复能流式出现，工具卡状态能从执行中变为完成。
- [ ] 选择“计划”后能看到 Grok 的计划更新。
- [ ] 停止按钮能取消当前任务。
- [ ] 触发写入前能看到权限选项，取消后任务不会继续写入。

## Git 与变更

- [ ] 顶部显示正确分支。
- [ ] 右侧“变更”列出正确的状态码与路径。
- [ ] 刷新按钮能更新未提交文件数量。
- [ ] 非 Git 文件夹不会被误报为 Git 仓库。

## 开源闸门

- [ ] 仓库仍为 Private。
- [ ] 没有 GitHub Pages、公开 Release 或部署工作流。
- [ ] Git 历史没有密钥、令牌、私人路径截图或测试会话内容。
- [ ] 用户已确认正式名称、许可证和 README 声明。
- [ ] 只有完成以上检查后，才允许改变仓库可见性。
